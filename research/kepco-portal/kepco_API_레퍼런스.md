## 0. 개요
- **형태**: 웹 포털(브라우저 접속) — 네이티브 앱 아님(쿠키 추출 용이).
- **인증**: 아이디/비번 + **OTP**. 세션 **30분 idle 만료(sliding — 쓰면 연장)**.
- **접근 전략**: 우리 권한 없음 → 권한자 OTP 로그인 세션을 맥 백엔드로 이식 → 백엔드가 그 세션으로 데이터 API 직접 호출. 아미큐 백엔드(`cst-input/backend/app.py`)의 SESSION / pull_session / _cookie_header / session_alive 패턴 재사용.
