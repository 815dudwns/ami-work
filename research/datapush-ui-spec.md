# DataPush 수집 모달 — UI 디자인 스펙 (디자인 의뢰용)

## 무엇인가
한국 전력 계량기(전기 계기) 교체 작업자가, 한 주소에서 교체한 설비 정보를 **현장에서 모바일로 수집**하는 화면. 수집한 데이터는 나중에 한전 시스템(awms 설비등록)에 자동 전송된다. 이 화면은 "수집"만 담당.

**가장 중요한 제약: 작업자가 현장에서 빠르게 쓴다. 입력이 많으면 안 쓴다. 최빈 케이스는 탭 몇 번으로 끝나야 한다.**

## 디자인 제약 (필수)
- 모바일 세로 화면 (폰). 전체화면 모달.
- 한국어 라벨만. **이모지·아이콘 문자(원문자 등) 절대 금지** (글자 깨짐). 텍스트 라벨로.
- 정보 밀도가 높지만 한눈에 위계가 보여야 함 (함체 > 마스터 > 슬래이브 중첩 구조).
- 색·여백으로 그룹 경계를 명확히. 지금 구현은 중첩 박스가 답답하고 사진 슬롯 배치가 불편하다는 피드백.

## 데이터 구조 (수집 대상)
계층: **주소 > 함체(1개 이상) > 마스터(1개 이상) > 슬래이브(0개 이상)**

### 함체 (물리적 계기함)
- 한 주소에 함체가 여러 개일 수 있음.
- 함체 종류 2가지 (작업자가 현장 보고 선택): **단독형 함체** / **집합형 함체**
- 함체마다 마스터가 1개 이상.

### 마스터 (모뎀을 꽂은 계기)
- 계기번호 (자동: 주소의 계기 목록에서 선택)
- 계기유형 (자동: 번호로 판별 — E / AE / G / AMIGO)
- **모뎀맥** (작업자 입력 또는 QR 스캔)
- **통신방식** (자동: 모뎀맥으로 판별. 실패 시에만 드롭다운 선택)
- 시설유형 (자동 산출, 아래 규칙)
- 함내계기수 (자동 산출)
- **사진** (작업자 촬영/앨범선택)

### 슬래이브 (마스터에 통신으로 물린 계기)
- 마스터 아래에 묶임 (계기 목록에서 그 마스터에 배정)
- 계기번호·계기유형 (자동)
- **사진** ← 이 부분 구조 미확정 (디자인 시 "슬래이브마다 자기 사진 슬롯"으로 자리 잡아둘 것)

## 자동 vs 수동
- **자동(작업자 입력 불필요)**: 계기번호, 계기유형, 시설유형, 함내계기수, 지사, 통신방식(맥으로)
- **수동(작업자 입력)**: 함체 종류(단독/집합), 마스터 지정, 슬래이브 묶기, 모뎀맥(QR), 사진

## 시설유형 자동판정 (마스터 행마다)
- 단독형 함체 + 슬래이브 없음 = **단독형** (이 경우 대표계기·함내계기수 표시 안 함)
- 단독형 함체 + 슬래이브 있음 = **집합형단독**
- 집합형 함체의 첫 마스터 = **집합형기본**
- 집합형 함체의 2번째 이후 마스터 = **집합형추가**
- 함내계기수 = 그 마스터 그룹(마스터 1 + 슬래이브 수). 함체별 따로, 합산 안 함.

## 사진
4종 (각각 정사각 썸네일 슬롯, 탭하면 앨범/카메라):
1. 시공전 (함체 내 모든 계기) — 마스터+슬래이브 공유
2. 모뎀맥 (모뎀 맥 적힌 곳 클로즈업) — 마스터+슬래이브 공유
3. 시공후1 (해당 계기) — 계기별 개별
4. 시공후2 (함체 내 모든 계기, 시공 후) — 계기별 개별
- 슬래이브 계기 사진: 시공전·모뎀맥은 마스터 것 공유, 시공후는 슬래이브 개별. (정확한 슬롯 수는 확정 중 — "5번 사진" 포함 여부 미정. 슬래이브마다 사진 영역 자리를 잡아둘 것)

## 핵심 인터랙션
1. 주소 진입 → 그 주소의 **미배치 계기 목록(풀)** 표시
2. 기본으로 함체 1개(단독형) 제공. 흔한 케이스(단독·마스터1·슬래이브0)는 모뎀맥+사진만 넣으면 끝.
3. 계기를 마스터로 지정 / 슬래이브로 묶기 (드래그 또는 버튼/체크)
4. 함체 추가 가능, 함체 종류 토글
5. 마스터마다: 모뎀맥(+QR버튼), 통신방식 자동표시, 사진 슬롯, 그 아래 슬래이브들
6. 하단 고정: "큐에 담기" 저장 버튼

## 레이아웃에서 풀어야 할 문제 (현재 불편한 점)
- 함체/마스터/슬래이브 3단 중첩이 박스 안의 박스라 답답함 → 위계를 색/들여쓰기/카드로 더 산뜻하게.
- 사진 슬롯 4개 + 슬래이브 사진이 한 마스터 카드 안에 많음 → 정리된 배치 필요.
- 미배치 계기 풀과 배치된 계기의 관계가 한눈에 안 들어옴.
- 자동값(시설유형/통신방식/함내계기수)을 "자동"임이 보이게, 수동 입력과 구분.
