## 1. awms-bridge 재정의 (통신팀 헬퍼 → 계기팀 완료추출 도구)

### 통신팀 헬퍼 호출 제거
- 기존 awms-bridge가 통신팀 원격 inject(loadRemoteInject) 호출하던 부분 제거
- 공유 inject.js(awms-helper 사용 중)는 수정하지 않아 awms-helper 무손상 유지

### 상단 짤림 해결
- awms-helper/jongno 검증 이식: `setDecorFitsSystemWindows(false)` + `android.R.id.content` insets 적용
- WebView 콘텐츠가 상태표시줄에 가려지던 문제 해결

### "완료받기" 버튼 baked-in 주입
- mobMtr1000/getMainList (workStep=28) 페이지 루프로 계기팀 완료 목록 수집
- 수집 결과 Firebase `awmscomplete/` 경로에 PUT
- 재빌드+설치 (패키지명: com.youngjun.awmsbridge)
- 초기 버그: 완료받기가 mobCst(통신팀) 호출해 0건 → 계기팀 엔드포인트 = mobMtr 확인 후 mobMtr1000/getMainList + busiKey=14차 로 수정

## 3. awms 계기교체 큐 자동등록 전체 규명 (핵심 성과)

### 목표
작업자 jongno 완료 → awms saveRow 자동 임시저장(큐). 헬퍼 개입 불필요한 구조 확인.

### CDP 인프라 발견
- awms 세션은 폰 awms-bridge WebView에만 존재 (OTP 2단계 인증, 4시간 만료). PC에서 직접 접근 시 403
- 우회: `adb forward tcp:9222 localabstract:webview_devtools_remote_<pid>` → CDP WebSocket `Runtime.evaluate`로 맥에서 폰 세션 빌려 fetch
- CDP 타임아웃 주의: 폰 절전 시 끊김 → `KEYCODE_WAKEUP`으로 유지

### 1건 등록 7단계 흐름
1. 봉인조회: `mobMtr8000/getMainList` (무파라미터) → 대상 계기 확인
2. `selectCustomerInfo`: 철거계기 기준 제조월·계약종별·고객번호 취득
3. 철거 saveRow: `mobMtr5000` → `consTgtSeqno` 발급
4. `getDetail`: `mobMtr1000` + consTgtSeqno → awms가 채운 301키 메타데이터 취득
5. `selectMtrlUseYn`: 신설 자재 MNFCT_YM·MTRL_NO 확인
6. 신설 saveRow: `mobMtr4000` (getDetail 베이스 + EX_WORK_STEP=25)
7. 봉인 saveRow: `mobMtr8000/saveRow` → 봉인 수량 추가

### 규명된 필드 출처

| 필드 | 출처 |
|------|------|
| 신설 제조월 | jongno `new_meter_mfg_ym` (작업자 입력) |
| 봉인 수량 | 단상+1, 삼상+2 (awms 자동 처리 안 함 — 큐가 mobMtr8000/saveRow 직접 설정) |
| 행 연결 | 철거 consTgtSeqno → 신설 CONS_TGT_SEQNO 주입 + EX_WORK_STEP=25 |
| 사진 | saveRow `_SRC` 필드에 Blob 직접 삽입 (DREMO_ATCH_FILE_ID_3_SRC=철거전, CREMO_ATCH_FILE_ID_3_SRC=철거후). innorix 불필요(awms-extension 교차 확인) |
| 지침 주간/야간 | 계약종별 905(심야전력갑) → DGD_WHME_NDL_MNGT_QTT, 그 외(100=주택용) → DGD_WHME_NDL_DAY_QTT |
| 단상/삼상 구분 | 계기번호 53=단상, 55=삼상 |

### 빌더 queue_saverow_builder.py 완성
- PM이 직접 디버그한 버그 3건:
  - CONS_NO stub (seal_info 미전달 문제)
  - 신설 build 순서 (consTgtSeqno 취득 전 호출)
  - 제조월 today_ym → jongno mfg_ym 교체
- 검증 결과: 철거·신설 saveRow HTTP 200, 1행 정상, 제조월(getDetail 반영), 봉인 단상+1/삼상+2 일관성(사례: 3967106→07→09)
- 사진+지침 주간야간 포함 통합 push는 세션 만료로 다음 세션 진행 예정
- 산출물: `research/awms-poc/queue_saverow_builder.py`

### 계약종별 코드 (getCommonCode 조회 확인)
- 100 = 주택용
- 905 = 심야전력(갑)
- 영준님 발견: "삼상 야간 활성 = 심야전기"
