# 2026-05-09 세션 로그

## ami-work — 모바일 브라우저 뷰포트 버그 수정

**문제**: 모바일 브라우저(Chrome/Safari)의 하단 주소창·네비게이션 바 때문에 계기 목록 맨 아래 항목이 가려지는 현상

**원인 분석**: `css/panel.css`의 `.fullpage-overlay`에 `height: 100vh` 사용 중. 모바일 브라우저에서 `100vh`는 브라우저 UI를 포함한 전체 높이로 계산되어, 실제 가시 영역(visible area)보다 크게 잡힘 → 하단 컨텐츠가 브라우저 UI에 가려짐

**수정 내용** (`css/panel.css`):
1. `.fullpage-overlay` — `height: 100dvh` 추가 (dvh = Dynamic Viewport Height, 실제 가시 영역 기준. 구형 브라우저 호환을 위해 기존 `100vh`도 앞에 유지)
2. `.overlay-meters` — `padding-bottom: max(16px, env(safe-area-inset-bottom))` 추가 (iOS 홈바 safe area 대응)
