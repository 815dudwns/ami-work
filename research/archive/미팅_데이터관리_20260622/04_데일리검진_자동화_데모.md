# 데일리 데이터 검진 자동화 — 데모 자료

> 미팅 핵심 무기. 데이터관리팀이 **매일 손으로 하는 검증을 그대로 자동화**한 것 → 그들에게 제일 필요. ②(돕고 수입)·③(공사수주) 입구.
> 톤 주의([[awms_kepco_risk]]): "awms 대신 올림" 금지. **"데이터 정리·검증·품질 보증"**으로만. 인쇄물에 awms 자동제출 안 넣기.

---

## 1. 그들이 매일 하는 일 (공감 — 먼저 이걸 말하게 한다)

작업자가 올린 계기번호·검침값·사진을 받아서:
- **빠진 거 없나** — 검침값·철거사진·신설사진·신설계기번호 누락 점검
- **사진이랑 입력값 맞나** — 계기번호·검침값을 사진과 눈으로 대조
- **엉뚱한 칸에 들어갔나** — 계약종별이 요구하는 필드(주간/야간/최대/무효)에 맞게 들어갔는지
- **한전 제출 가능한 상태인가** — 최종 검증 후 보고

→ 사람이 종일 눈으로 대조. 물량 많으면 전수 못 보고 샘플만. **사람 손입력이라 실수는 불가피**.

## 2. 우리 데일리 검진 = 이걸 자동화 (매일 마감 후 그날 작업분 전수)

| 단계 | 자동으로 하는 일 | 사람이 손으로 하던 것 |
|---|---|---|
| ① 누락 점검 | 검침값/철거사진/신설사진/신설계기번호 빠진 것 자동 검출. **계약종별별 필요필드**(주간·야간·최대·무효)를 자동 산정해 비교 | 한 건씩 빠진 항목 눈으로 확인 |
| ② 정합성 판정 | 계약종별 기준 **벗어난 칸**, 자릿수 오류, 단상↔삼상 **위상 불일치** 자동 플래그 | 칸 잘못 들어간 것·뒤바뀐 것 대조 |
| ③ OCR 사진 대조 | 계기판 사진에서 **계기번호·검침값 자동 추출 → 입력값과 자동 대조** (PARSeq → 구글비전+YOLO 캐스케이드) | 사진 열어 번호·검침값 한 자씩 대조 |
| ④ 사람 판정 | 자동 통과분 제외, **애매한 것만** 검증 페이지(URL)로 넘김 | 전건을 사람이 검토 |

**핵심: 전수를 자동으로 1차 거르고, 사람은 의심건만 판정.** 물량이 늘어도 사람 손이 안 늘어남.

## 3. 오늘 실측 데모 (2026-06-25) ※검진 완료 후 수치 확정

- 작업 **123건** (연번 구멍 0 = 앱작성 누락 0, 전부 정식 완료)
- **누락 0건 / 정합성 위반 0건** — 검침값·철거사진·신설사진·신설계기번호 전부 123/123 완비. 종별 벗어난 칸·자릿수·위상 불일치 모두 0.
- OCR 검침값: 자동통과 123 / 2차통과(구글비전) 9 / **사람검토 6**
- 계기번호 대조: 신규 **123건 전부 일치**(의심 0) / 철거 사람검토 3
- → **123건 중 사람이 실제로 판정할 건 단 9건**(검침값 6 + 철거번호 3). 나머지 114건 = 100% 자동 처리.

> 가장 강한 한 방(기존 실측): 사진 OCR로 awms 입력오류 **21건 자동 검출**(6/9·5/9·0/8 혼동, 자리바뀜, 신설계기 누락). "사람 탓이 아니라, 손입력은 원래 실수 나기 마련이고 사진으로 자동으로 걸러준다."

## 4. 그들에게 주는 것 (이득 프레임)

- **종일 눈대조 → 자동.** 사람은 의심건만 판정 = 시간 급감, 실수 급감.
- **한전 제출 데이터 품질 ↑** — 사진(실물)이 심판. EXIF·촬영시각 무조작.
- **자존심 안 건드림** — "당신이 틀렸다"가 아니라 "손입력은 원래 실수가 나는데 그걸 자동으로 메운다".
- 물량이 늘어도 사람 안 늘려도 됨 = 그들 부담 감소.

## 5. 수익 연결 ([[03_업무자동화_아이디어]])

- **건당 과금**(검증 건당) 또는 **월 구독**으로 가볍게 시작 → 신뢰·데이터 쌓고 내년 데이터관리 공사(③)로 확장.
- 1년 누적 데이터 = 재계약 leverage([[business_strategy]]).

## 6. 보여줄 때 순서 (미팅 현장)

1. "데이터 받으면 빠진 거·맞는 거 매일 대조하시죠?" → 그들이 공감·설명하게
2. "우리는 그걸 매일 자동으로 돌립니다" → 위 4단계 그림
3. "오늘 것도 돌렸는데 123건 중 사람이 본 건 __건뿐이에요" → 실측
4. "이거 그대로 데이터관리에 얹어드릴 수 있어요" → ② 입구
