# 데이터관리자 미팅 — 전략 개요

작성 2026-06-22 / 대상: 다른 쪽 계기팀 데이터 관리자 / 목표: 내년 데이터관리 공사 수주 기반 마련

---

## 1. 이 미팅의 목적은 4갈래다 (섞어 꺼내지 말 것)

| 목적 | 우리가 하는 것 | 상대가 느끼는 것 |
|---|---|---|
| ① 배우기 | 인입설계·신규계기·awms 관리자페이지 질문 | "관심 있게 물어보네" (호감) |
| ② 팔기·돕기 | 그들 업무를 편하게 하는 도구 제공 → 수입 | "내 일이 편해진다" (이득) |
| ③ 공사 따기 | 내년 데이터관리 자리 확보 | "내 자리를 뺏을 수도" (경계) ← 위험 |
| ④ 데려오기 | 베테랑 스카우트 | "이직 제안?" (민감) |

## 2. 핵심 긴장 — 반드시 인지

**③과 ④는 상대 입장에서 위협이다.**
우리가 "데이터관리 공사를 딴다" = 지금 그 일을 하는 사람의 밥줄. 첫 미팅에서 ③을 드러내면 상대는 정보도 안 주고 닫힌다.

→ **해소법은 순서와 프레임:**
- 먼저 ①(배우기) + ②(당신을 편하게 해줄 도구)로 **신뢰와 이득**을 만든다.
- 관계가 생긴 뒤에야 ③/④를 꺼내되, **"내가 네 자리 뺏는다"가 아니라 "우리 시스템 + 너의 도메인 지식 = 같이 더 큰 걸 딴다"** 로 합류 프레임.
- 이건 우리 기존 전략과도 일치: 베테랑은 외주가 아니라 **직원으로 채용, 계약까지 동행**([[business_strategy]]).

## 3. 권장 미팅 순서

1. **가볍게 시작** — "현장에서 같이 일하다 보니 데이터 쪽이 궁금해서, 어떻게 돌아가는지 배우고 싶었다." (배우기 명분)
2. **그들 워크플로우 경청** (01 질문지) — 인입설계·신규계기·awms 관리자페이지·하루 흐름. 취조 아닌 관심.
3. **우리 시스템 슬쩍 보여주기** (02 소개) — "우리는 현장 입력을 이렇게 자동화했다" → 상대가 "그거 우리도 되나?" 하게.
4. **상대 업무 자동화 떡밥** (03 아이디어) — "당신이 제일 귀찮다는 그거, 자동화할 수 있을 것 같다." → ②(돕고 수입) 입구.
5. **③/④는 분위기 봐서만** — 상대가 우리에게 호감/신뢰를 보일 때만. 아니면 다음 미팅으로.

## 4. 절대 주의 (사고 방지)

- **awms 자동화는 톤 조심** — "awms 대신 올려준다"는 한전 정책 우회로 비친다([[awms_kepco_risk]]). "데이터 정리·입력 보조·검증"으로만 표현. 인쇄물엔 awms 자동제출 안 넣기.
- **"데이터관리팀이 틀렸다"는 무기 절대 금지** — 실측 결과 데이터관리팀은 오히려 정확했다(실물 사진 기준). 적은 사람이 아니라 "사람이 하는 awms 입력의 불가피한 오류"다([[business_strategy]] 반전 결론). 상대를 깎으면 즉시 역공당하고 관계도 끝.
- **B2B 관계 존중** — 강제 못 한다. 항상 "상대 이득이 먼저 보이게"([[jongno_meter_team_b2b]]).
- **한전이 아니라 공사대행(탑성천)이 의사결정자** — 영업 언어는 한전 정책이 아니라 "행정 효율"([[industry_chain]]).

## 5. 우리가 가진 패 (협상 자산)

- 현장 입력 디지털화 (계기큐·종로맵·헬퍼) — 이미 실작업 중, 데모 가능
- 사진 OCR로 awms 입력오류 자동검출 — **실측 21건 검출**(데모 무기)
- 관리자/검증/리포트 페이지 비전 — 데이터관리 자리 그 자체
- 우리가 못 가진 것 = 인입설계 도메인 → 이게 상대(또는 베테랑)에게서 채워야 할 빈칸
