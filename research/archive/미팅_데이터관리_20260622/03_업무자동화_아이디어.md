# 그들 업무 자동화 아이디어 (② 돕고 수입 내기)

> 목적: 상대 업무를 자동화해 **지금 당장** 신뢰 쌓고 수입을 낸다. 이게 ③(내년 공사)·④(스카우트)로 가는 가장 빠른 입구.
> 핵심: 미팅 질문지 D-24("제일 귀찮은 작업 3가지")의 답이 우선순위를 정한다. 아래는 후보.

---

## 자동화 후보 (난이도 낮음 → 가치 높음 순)

### 1. 수기 대조 → 사진 OCR 자동검증  (이미 됨, 바로 데모)
- 그들이 손으로 하는 "계기번호·검침값 맞나" 대조를 사진 OCR로 자동.
- 우리가 이미 실측(21건 검출). 상대 업무에 그대로 얹기만 하면 됨.
- 수입: 검증 건당 과금 또는 월 구독.

### 2. 한전 제출 엑셀 자동 생성
- 작업 데이터 → 한전(또는 공사대행) 제출 양식 엑셀을 버튼 하나로.
- 그들이 매일·매주 손으로 만드는 보고서를 자동화.
- 수입: 개발 1회 + 유지보수, 또는 구독.

### 3. 사진 정리·링크 자동화
- 계기별 철거·신설·검침 사진을 자동 분류·이름표·압축·보고서 링크.
- 그들이 사진 찾고 정리하는 시간 제거.
- (우리 종로 사진 zip 정리 파이프라인을 응용 가능)

### 4. awms 등록 보조 (톤 조심)
- awms 입력의 반복 부분을 보조(헬퍼 방식). "대신 올림"이 아니라 "옮겨적기 줄임"으로.
- 한전 리스크 있으니 **옵션·부가**로만. 인쇄물 X.

### 5. 인입설계 자재 산정 계산기 (베테랑 채용 후)
- 거리·오차 변수 입력 → 자재 수량 자동 산정. 결과는 **베테랑이 검토**(책임 분리).
- 지금 단독으로 만들지 말 것 — 도메인 모름. 미팅에서 "이거 계산 프로그램으로 만들 수 있겠다" 감만 잡기.
- 가장 어렵지만 차별화 큼. ④(베테랑 합류)와 묶임.

## 수익 모델 옵션 (상대·공사대행과 협의)

| 모델 | 설명 | 적합 |
|---|---|---|
| 건당 과금 | 처리·검증 건당 (예: 데이터관리 대행 개당 1,000원) | 물량 많을 때, 첫 매출 입구 |
| 월 구독 | 도구 사용료 정액 | 안정적 관계, 락인 |
| 개발 용역 | 그들 전용 자동화 1회 개발 + 유지보수 | 맞춤 요구 있을 때 |

→ 1차는 **건당 또는 작은 구독**으로 가볍게 시작해 신뢰·데이터 쌓고, 내년 ③(데이터관리 공사 수주)로 확장. 1년 계약은 데이터 누적이 재계약 leverage([[business_strategy]]).

## 미팅에서 던질 한 문장 (떡밥)

- "제일 귀찮다고 하신 그거, 우리가 자동화해서 시간 확 줄여드릴 수 있을 것 같은데, 한번 만들어볼까요?"
- 작게 하나 만들어주고 → "오 이거 편하네" → 신뢰 → 더 큰 얘기(③④).
