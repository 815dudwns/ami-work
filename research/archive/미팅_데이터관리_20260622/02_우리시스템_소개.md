# 우리 시스템 소개 (상대에게 보여줄 자료) — 상세판

> 원칙: 기능 자랑 X, **상대 이득** 중심. "awms 자동제출" 세게 말하지 말 것 → "입력 보조·정리·검증"으로([[awms_kepco_risk]]).
> 한 줄 메시지: **"현장에서 한 번 입력하면, 정리·검증·보고까지 알아서 됩니다. 같은 걸 두세 번 옮겨 적을 필요가 없어요."**

---

## 1. 우리가 푸는 문제 (상대가 공감할 지점 — 구체적으로)

지금 현장 흐름:
1. 작업자가 **awms 앱에 계기교체 입력**
2. 종이 출력물에 **계기번호·검침값 수기**
3. **사진 따로 촬영**
4. → 데이터관리팀이 받아서 **번호·검침값·사진 재대조**, 틀린 거 찾아 작업자 재요청, 한전 제출 양식으로 정리

= **같은 데이터를 2~3번 옮겨 적고, 사람이 눈으로 전수 대조.** 물량 많으면 다 못 보고 샘플만 → 오류가 한전까지 흘러감.

→ 우리는 이 **이중·삼중 입력과 수기 대조를 없앴습니다.**

## 2. 각 도구 상세

### 종로맵 — 현장 입력 본체
- 작업자가 **지도에서 계기 위치를 찍고 그 자리서 입력**. 종이 출력물·수기 불필요.
- **검침값 칸이 계약에 맞춰 자동 결정**: 계약종별·계약전력을 보고 필요한 필드(주간/야간/최대전력/무효)를 자동으로 띄움. **1종·2종 4필드 계기도 지원** → 작업자가 어느 칸에 뭘 넣을지 헷갈릴 일이 없음.
- 철거·신설 사진, 계기번호, 봉인, 추가계기를 **한 화면에서** 입력.
- **LCD 자동검출(YOLO 온디바이스)**: 계기판 사진을 고르면 검침 LCD 영역을 자동으로 잡아 입력을 보조.
- 결과: **데이터가 처음부터 디지털**이고 위치·촬영시각·사진이 한 건으로 묶임.

### 계기큐 — awms 등록 보조
- 종로맵에 입력된 걸 **awms 설비등록에 올리는 반복작업을 보조·일괄화**.
- **차수·봉인 자동 관리**, **이미 올린 건은 자동 제외(중복 등록 방지)**.
- awms로 옮겨 적던 시간이 급감.

### 헬퍼 — 설비등록 자동입력
- awms 설비등록 화면의 **반복 입력(지사·통신방식·분기·스캔 등)을 자동으로 채움**.
- 손이 많이 가던 등록을 클릭 몇 번으로.

### 관리자·검증 페이지 + 데일리 검진 ([[04_데일리검진_자동화_데모]])
- **매일 마감 후 그날 작업분을 자동 검진**: ①누락 점검 → ②정합성(계약종별 맞는 칸·자릿수·단상삼상) → ③OCR 사진 대조 → ④**의심건만 사람**.
- **통계·엑셀 내보내기**: 비고·지침사진 하이퍼링크·열너비까지 **한전 제출 양식 그대로**.
- **오늘 실측(6/25)**: 123건 자동 검진 → 사람이 본 건 9건, 실제 수정 2건.

### 사진 OCR 검증 — 핵심 무기
- 계기판 사진에서 **검침값·계기번호를 자동 추출 → 입력값과 자동 대조**.
- **검침값 캐스케이드**: 1차 PARSeq → 통과 못 한 것만 구글비전+YOLO 2차 → 그래도 애매한 것만 사람. (대부분 자동 통과, 사람은 소수만)
- **계기번호**: Apple Vision으로 사진에서 번호 추출 → DB값과 대조.
- **폰 안(온디바이스)에서도 작동** → 서버·통신 의존 최소.
- 실측: awms **입력오류 21건 자동 검출**.

## 3. 데모 시나리오 (현장에서 보여줄 순서)

1. **종로맵 입력 화면** — "검침값·사진·계기번호가 한 번에 들어가고, 칸은 계약에 맞춰 자동으로 떠요."
2. **데일리 검진 결과** — "오늘 작업 123건을 자동으로 다 검증했어요."
3. **리뷰 URL 화면** — "사람이 봐야 할 건 9건만 이렇게 띄워줍니다." (실제 폰으로 시연)
4. **엑셀 내보내기** — "한전 제출 양식으로 버튼 하나에 나옵니다."

## 4. 데모 포인트 (실측 — 가장 강한 한 방)

- **사진(실물)으로 awms 입력값을 자동 대조해 입력오류 21건을 잡아냈습니다.**
- 사람이 손으로 넣다 보면 생기는 혼동(6/9, 5/9, 0/8, 자리바뀜, 신설계기 누락)을 **사진을 심판 삼아 자동 검출**.
- 메시지: "사람을 탓하는 게 아니라, **손입력은 원래 실수가 나기 마련**이고 그걸 사진으로 자동으로 걸러준다." (상대 자존심 안 건드림)

## 5. 데이터 안전 (신뢰 포인트)

- 작업자 저장분이 동시작업·중복으로 날아가지 않게 **저장이력 자동 백업** 운영(2026-06-21 적용).
- 사진은 **EXIF·촬영시각 무조작** 유지 → 한전 데이터 품질을 **오히려 높임**.
- **오프라인 캐시**로 현장 통신이 약해도 입력·조회가 끊기지 않음.

## 6. 포지셔닝 (말로 할 때)

- "우리는 한전 대신 뭘 해주는 게 아니라, **현장 데이터를 깔끔하게 만들어 넘기는 쪽**입니다."
- "데이터관리하시는 분 일을 **뺏는 게 아니라 편하게** 만드는 도구예요."
- (③ 분위기 좋을 때만) "이런 시스템에 **현장 도메인 아는 분**이 붙으면, 데이터관리를 통째로 더 잘할 수 있겠다 싶어요."

### 인쇄/화면용으로 추릴 1장 (실제 보여줄 때)
1. **문제 그림**: 같은 데이터 2~3번 옮겨적기 + 사람 눈 대조
2. **우리 흐름**: 현장 1회 입력 → 자동 정리 → 자동 검증 → 보고
3. **실측 수치**: 사진으로 입력오류 21건 자동검출 / 오늘 123건 중 사람 9건만
4. (awms 자동제출은 **말로만**, 인쇄물엔 빼기 — [[awms_kepco_risk]])
