# 아미큐(통신팀) 풀 네이티브 재작성 계획 (Kotlin + Jetpack Compose)

결정(2026-07-01): 웹뷰 원격로드 구조의 UX 불편(뒤로가기 리셋·복귀 상태소실·세션 왔다갔다·백엔드 연결 번거로움)을
근본 해결하기 위해 **풀 네이티브(Compose) 재작성**. 맥 백엔드는 유지(OCR=애플비전, awms 세션 보관, saveAct 전송).

## 원칙
- **applicationId `com.youngjun.cstinput` + 기존 키스토어 그대로 유지** → 자동업데이트 연속성(서명 일치, 전폰 재설치 방지). ★키스토어 백업 필수.
- 맥 백엔드 API는 그대로 재사용: `/api/session` `/api/session/push` `/api/config` `/api/commtype` `/api/ocr` `/api/saveact/stream`(진행표시)·`/api/saveact`(폴백). 전송 대상 = 맥(awms 직접 아님).
- 풀 네이티브의 비용 = **코드 변경 시 매번 APK 재설치**(push 즉시반영 상실). 대신 UX·안정성 확보.

## 기술 스택
- Kotlin + Jetpack Compose (Material3, 자체 다크 --mint:#3ddc97 팔레트 이식)
- Navigation-Compose (화면 전환·뒤로가기 네이티브)
- OkHttp (맥 백엔드 호출 + NDJSON 스트림 readLine으로 진행표시)
- ActivityResultContracts.PickMultipleVisualMedia (네이티브 포토피커 = 다중선택 정상, 웹뷰 "1장만" 버그 제거)
- GmsBarcodeScanner (기존 dep 유지 — QR/바코드)
- 네이티브 WebView(AndroidView) = awms 로그인 전용 화면(메인 UI 안 떠남 → 상태소실 없음)
- 유지: KdnNotificationListener/OtpReaderService(OTP 카톡 자동수집), UploadWorker(백그라운드), 필요시

## 화면 구성 (Compose Navigation)
1. **설정/홈** — 지사, awms 계정, 공사(awms 자동취득), 백엔드 연결, 세션상태 + [awms 로그인], 버전
2. **awms 로그인** — 네이티브 WebView 전용화면. id/pw/OTP 자동입력 → CookieManager 쿠키 → 맥 /api/session/push → pop(메인 상태 보존). "왔다갔다" 해결.
3. **수집** — 마스터사진(4) → 슬레이브사진 → 모뎀맥+통신방식 → 계기번호 확인 → 전송(진행바). 뒤로가기 네이티브.
4. **큐(다음 단계)** — 수집한 세대(마스터+슬레이브) 여러 건 누적 → 일괄 전송. 수집화면이 큐에 add하는 구조로 설계.

## 단순화 포인트 (영준님 요청 직결)
- **백엔드 연결 단순화**: 맥이 터널 URL을 QR로 표시 → 폰에서 1회 스캔(이미 스캐너 있음) → 저장. URL 손입력 제거.
- **세션 왔다갔다 단순화**: awms 로그인이 별도 네이티브 화면 → 로그인 후 자동 복귀, 메인 화면/입력값 그대로 유지. localhost 튐·뒤로가기 리셋 소멸.
- **수집 왔다갔다 편하게**: Navigation back stack으로 단계 이동 자유. 입력 상태는 ViewModel(rememberSaveable)로 보존 → 앱 복귀/회전에도 안 날아감.

## 단계별 구현 (phase)
- **Phase 1 — 골격+백엔드+세션**: Compose 셸, 설정화면, 백엔드 QR 페어링, awms 네이티브 로그인→세션 push, 세션상태. ("단순 연결·단순 세션" 실증)
- **Phase 2 — 수집 플로우**: 네이티브 사진피커·맥스캔·통신방식·계기확인, 전송+스트림 진행바. (수집 UX·상태소실 해결)
- **Phase 3 — 큐**: 세대 누적 리스트, 일괄 전송, 편집/삭제.

## 리스크·유의
- Capacitor 제거 vs 공존: 안전하게 기존 app 모듈에 Kotlin+Compose 추가, MainActivity를 ComponentActivity로 교체(Capacitor Bridge 미사용). google-services/OTP/UploadWorker 유지.
- 키스토어 서명 연속성(자동업데이트) — 릴리스 서명 동일 확인.
- OCR은 맥 애플비전 유지(온디바이스 ML Kit 정확도 검증 전까지). 네이티브가 base64 전송.
- 통신방식 판별·슬레이브 상속·fid 스레딩은 **맥 백엔드에 그대로**(검증완료 로직 재사용). 네이티브는 UI+수집만.
