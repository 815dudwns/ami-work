# awms 미연계 검증 프로세스 (통신팀↔계기팀 대조)

> 종로 동행시공: 계기팀(계기교체) + 통신팀(모뎀설치) 데이터 대조로 누락/오타 잡는 정기 작업.
> 2주에 1회 리스트 뽑아서 처리. API 호출법은 `awms_API_레퍼런스.md` 섹션 8(통신팀) 참조.
> 2026-06-06 최초 작성 (누상동 166-55 1/15 추적에서 시작).

---

## 1. 용어/구조

- **미연계** = 계기팀이 교체 완료(replacement 존재)인데 **통신팀 전송리스트에 매칭 안 되는 계기**.
- **매칭축**: 통신팀 `INSTR_NUM`(계기번호) = 종로 `new_meter_id`(신설계기번호). MB_METER_ID도 보조 매칭.
- **통신팀 완료** = 종로 `comm_completed_list/{구계기}`. 계기팀 완료 = `replacement_list/{구계기}`.

### 통신팀 함(모뎀) 시스템 — 핵심
- **MB_METER_ID = 대표계기(마스터)**. 같은 함의 모든 계기가 공유.
- **MB_CNT = 함내 계기수** (통신팀이 작업 시 입력).
- **MODEM_DIV: 10=마스터, 20=슬레이브**. MAC_MODEM = 모뎀 1개.
- 통신팀은 **함 단위로 완결**(MB_CNT = 실제 전송수, 함내 누락 거의 없음). 누락은 "함 자체 미작업" 또는 "번호 오타".

## 2. 3자 데이터 (진실 판별)

| 출처 | 내용 | 신뢰도 | 받는 법 |
|---|---|---|---|
| **사진(실물)** | 계기판 제조번호 = 계기번호 | **최상(진실)** | 통신팀 getDetail → ATCH_FILE_ID_5(시공후1) → singleFile |
| **통신팀(cst)** | 현장서 INSTR_NUM 입력 | 상 (현장 실측) | MOBCST getMainList (섹션8) |
| **계기팀awms(MOBMTR)** | 계기팀 awms 직접등록 CREMO | 상 (단 최근2달만) | MOBMTR getMainList 전차수 |
| **한전준공엑셀(kepco)** | 한전이 책상서 정리 | 중 (오타 잦음) | `data/종로_실효리스트_*/*.xlsx` 준공내역서 |

- **계기번호 = 제조사(앞2) + 형식(2) + 제조번호(7)**. 예: 사진 `92-19-0665510` → 계기번호 `92190665510`.
- **import 파싱은 무결** 확인됨(엑셀값=종로DB값 100%). 오타는 **한전엑셀 원본 결함**이지 import 탓 아님.

### 계기팀awms 한계 (중요)
- 계기팀awms는 **최근 2달(13·14·20차)만** ≈ 1,120건. Amigo(0753) 위주.
- **AE타입(9219, E/EA)은 0건** — 5~12차 옛 작업이라 awms에 없고 **한전엑셀로만** 존재.
- → AE타입 대량주소(누상동·옥인 등)는 계기팀awms 대조 불가 = **사진/현장만**.

## 3. 판명 로직

### 미연계 분류
1. 통신팀에 **1자리 차** 번호 존재 → 통신팀이 작업함. 사진으로 판명:
   - 사진 = 통신팀번호 → **계기오타** (한전/awms 틀림, 통신팀 맞음)
   - 사진 = 계기팀번호 → **통신오타** (통신팀 틀림)
2. 통신팀에 **2자리 차** → 미판명. 대량주소(20~30개)는 비슷한 번호 많아 우연 가능 → **반드시 사진/현장**.
3. 통신팀에 **근접번호 없음** → 통신팀 미작업 → **(통신오타/미작업)**.

### 계기팀 내부불일치 (한전엑셀 ≠ 계기팀awms)
- 계기팀awms 유효값 = **계기팀 현장 정정** (계기팀awms 채택).
- 계기팀awms 빈값/구계기복사/자릿수오류 = **입력누락(불량)** → 한전엑셀 유지.

### 판명 난이도
- **4/5, 5/6 등 소수 대상** = 비슷한 계기 적음 → 오타 확실, 바로 판명.
- **20~30개 대량주소** = 비슷한 번호 많음 → 매칭 우연 변수 → 사진/현장 필수.

## 4. 사진 판명 (통신팀)

```
1. getDetail?FLAG=M10&DEPT1=3970&BUSI_NUM=C11G250023&INSTR_NUM={통신팀번호}&MAC_MODEM={mac}&EXT_FCTY_ID=-&DATA_NUM=&EXT_DCU_ID=
   → ATCH_FILE_ID_3~6 (3=시공전, 5=시공후1=계기번호 보임)
2. singleFile.innorix?atchFileId={fid}  → 이미지 바이너리(arrayBuffer→btoa)
3. 사진의 제조번호 = 실물 계기번호
```
- 도구: `cdp_eval_q.py`(포트 다름) / 통신팀=helper(awmshelper), 계기팀=queue(awmsqueue).
- 폰 A33(SM-A336N). helper=통신팀(우영준/장진교 729201), queue=계기팀(mdp/mmp).

## 5. 2주 1회 운영 흐름

1. **통신팀 전송리스트 최신 수집** (MOBCST getMainList, A33 helper 세션).
2. **계기팀awms 수집** (MOBMTR getMainList 전차수, A33 queue 세션) — 최근분만.
3. **미연계 리스트 추출**: 종로 replacement 중 통신팀 미매칭 → 엑셀.
   - 컬럼: 주소 / 구계기 / 계기팀신설번호 / 소스 / 통신팀근접번호 / 차이(1자리/2자리/없음) / 판정.
4. **판명**:
   - 최근타입(Amigo 등) → 계기팀awms 3자 대조.
   - AE타입·대량주소 → 사진/현장.
5. **처리** (영준님 지시: **소스 안 바꿈**):
   - 계기오타(통신팀 맞음) → 번호 그대로, `comm_completed_list`에 완료도장만. 계기에 `(계기오타)` 표시.
   - 통신오타 → `(통신오타)` 표시, 주소 노란색.
   - 계기팀 정정건 → 계기팀awms 채택 검토.
