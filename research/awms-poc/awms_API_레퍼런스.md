# awms.kdn.com API 레퍼런스 — 인덱스 (2026-07-29 팀별 분리)

> ★ 이 문서는 **포인터**다. 내용은 팀별 파일로 갈라졌다.
> awms는 작업 주체별로 모듈·엔드포인트·계정이 완전히 분리된 두 시스템이라, 한 파일에 두면
> 계기팀 API를 통신팀 절에서 찾는 사고가 난다(실제로 검침값 수정 API가 통신팀 §8.6에 묻혀 있었음).

| 팀 | 문서 | 베이스 | 쓰기 API | 계정 |
|---|---|---|---|---|
| **계기팀** (계기 철거/신설) | **`awms_API_레퍼런스_계기팀.md`** | `mob/mtr` (MOBMTR) | **`saveRow`** (mobMtr4000/5000/8000) | mdp/mmp (예 `mdp2504381`) |
| **통신팀** (모뎀/통신망 시공) | **`awms_API_레퍼런스_통신팀.md`** | `mob/cst` (MOBCST) | **`saveAct`** (mobCst1000) | 우영준/장진교 (예 `729201`) |

**★ 교차 호출 금지** — 통신팀 세션으로 `mob/mtr` 호출 시 405, 반대도 동일. 계정 권한부터 분리돼 있다.

**★ 자주 헷갈리는 것**
- `saveAct`는 **통신팀 전용**이다. 계기팀엔 saveAct가 없다.
- `28`은 API 이름이 아니라 **작업단계(`WORK_STEP`) 값**이다 (20 대기 / 25 임시저장 / 28 완료 / 29 전송완료).
  계기팀에서 완료(28) = `mobMtr4000/saveRow`에 `WORK_STEP=28`+`EX_WORK_STEP=25`.
  통신팀에서 29(전송완료) = 28 저장 후 `sendSelections`.
