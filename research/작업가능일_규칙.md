# 종로 동행시공 작업가능일/합동시공일 규칙 (2026년 5월 검증)

검침일(한전 정기검침일) 기준으로 계기교체 **작업가능일(노란색)**과 **합동시공일(살구색)**을
산출하는 규칙. 2026년 5월 검침일 1~31 정답 테이블을 **31개 전수 100% 재현(불일치 0)** 확인.

> 검증 명령: `node verify.cjs` → "전체 31개 검침일 완전 일치 (불일치 0)"
> 주의: 아래 규칙 중 일부(stall 집합, A 패치, 공휴일 집합)는 정답 테이블에서 **역산한 경험적 상수**다.
> 구조적 규칙(블록·합동칸수·Jstart)과 명확히 구분해 표기했다. **2026년 5월 전용 검증**이며 타 월 일반화는 보장 안 함.

---

## (a) 확정 규칙 서술

전체는 "기준년월의 영업일을 1번부터 번호 매긴 뒤(b1, b2, ...), 검침일마다 그 영업일 번호 구간을 잘라 쓰는" 구조다.

### 1. 영업일 인덱스 (b-index)
기준년월 1일부터 다음다음달 말일까지 중 **주말(토·일)과 비영업일(아래 (b))을 뺀 날**을
순서대로 b1, b2, b3 ... 로 번호 매긴다.
- 2026년 5월 기준: b1=5/4, b2=5/7, b3=5/8, b4=5/11 ... b18=6/1, b22=6/5, b23=6/8 ...

### 2. 블록 시작 슬롯 c(k)  — (구조 + 경험적 stall)
검침일 k에 대해
```
c(k) = (k + 1) − (k 이하의 stall 개수)
stall 집합 = {2, 3, 6, 10, 18, 23, 31}   ← 경험적 상수(테이블 역산)
```
- stall은 "그 검침일에서 블록 시작이 직전과 같아지는(밀리지 않는)" 지점.
- stall 집합은 **날짜 속성으로 환원 안 됨**: 영업일 월요일(k=18)도 stall이고, 주말(k=16,17)은 stall이 아니다.
  → 손으로 맞춘 롤링 배치의 산물이므로 상수로 박는다.

### 3. 메인 블록 = 연속 영업일 [c(k) .. c(k)+L−1]
```
L(전체 블록 길이) = 12  (k ≤ 16)
                  = 11  (k ≥ 17)        ← 구조적
```
이 블록의 **마지막 jlen칸 = 합동시공(J)**, **나머지 앞부분 = 작업가능(B)**.
```
jlen(합동 칸수) = 2  (k ≤ 18)
               = 3  (k ≥ 19)            ← 구조적
합동 시작(Jstart) = 블록끝 − jlen + 1   = (작업가능 끝 + 1)   ← 항상 성립
```

### 4. 전월잔여 A (검침일 15 이상에서만)
검침일이 15일 이상이면, 현재 표시월의 **앞쪽 영업일 구간**이 추가로 붙는다(전월 사이클의 잔여작업이
표시월 초반으로 넘어온 wrap-around).
```
Aend = c(k) − 10
   단, k=15 → Aend=1,  k=17 → Aend=3   ← 경험적 패치(둘 다 c−11에 해당)
Astart = max(1, Aend − 11)             ← A 최대 길이 12칸으로 자동 클램프
A = 영업일 [Astart .. Aend]
k < 15 이면 A 없음.
```

### 5. 최종 결과
```
작업가능(노란) = (A ∪ B) 를 날짜순 정렬
합동시공(살구) = J
```

### 구조 vs 경험적 구분 요약
| 항목 | 종류 |
|---|---|
| 영업일 인덱스, 블록=연속영업일 [c..c+L−1] | 구조적 |
| L (12→11), jlen (2→3), Jstart=Bend+1 | 구조적 |
| A 구간 = [max(1,Aend−11) .. Aend], Aend=c−10 골격 | 구조적 |
| stall 집합 {2,3,6,10,18,23,31} | 경험적 (역산) |
| A 패치 k=15→1, k=17→3 | 경험적 (역산) |
| 비영업일(공휴일/정기검침) 집합 | 경험적 (역산) |

## (b) 2026 비영업일 목록 (테이블 역산 — 5월 전용)

주말(토·일) 외에 **영업일에서 제외**되는 날(상수 `HOLIDAYS_2026`):

| 날짜 | 성격 |
|---|---|
| 2026-05-01 (금) | 근로자의날 — 법정공휴일 아니나 테이블상 제외 |
| 2026-05-05 (화) | 어린이날 (공휴일) |
| 2026-05-06 (수) | 정기검침일/표 제외 (실제 공휴일 아님, 테이블이 제외) |
| 2026-05-25 (월) | 부처님오신날(5/24 일) 대체공휴일 |
| 2026-06-10 (수) | 표 제외 (정기검침 추정, 테이블이 제외) |

**6/3(수) 불일치 주의**: 6/3 제9회 전국동시지방선거일은 실제로는 **임시공휴일(확정)**이지만,
정답 테이블은 6/3을 **영업일로 취급**한다(검침일 12·13·25 등의 구간에 6/3 포함).
지시상 "테이블이 진실"이므로 6/3은 영업일로 두었다. 실제 운영 적용 시 영준님 확인 필요.

참고(테이블 범위 밖이라 미반영): 6/26·6/29·6/30 등 6월 후반 영업일은 테이블이 6/25까지만
다뤄 검증 불가.

## (c) JS 함수 전문

종로앱 바닐라 JS에 그대로 삽입 가능. `getWorkableDates(검침일, 기준년, 기준월)` → `{workable, joint}` (YYYY-MM-DD 배열).

```js
// 2026 비영업일(주말 제외) — May 2026 전용 검증. 테이블 역산 결과.
// 주의: 6/3 지방선거 임시공휴일은 실제 공휴일이나 정답 테이블이 영업일로 취급 → 제외하지 않음.
const HOLIDAYS_2026 = new Set([
  '2026-05-01', '2026-05-05', '2026-05-06', '2026-05-25', '2026-06-10',
]);

function ymd(d) {
  const y = d.getFullYear();
  const m = String(d.getMonth() + 1).padStart(2, '0');
  const day = String(d.getDate()).padStart(2, '0');
  return `${y}-${m}-${day}`;
}

// 기준년월 1일 ~ 다음다음달 말일까지 영업일 목록 (블록이 다음달로 넘어가므로 2개월 여유)
function buildBusinessDays(year, month) {
  const out = [];
  const start = new Date(year, month - 1, 1);
  const end = new Date(year, month + 1, 0);
  for (let d = new Date(start); d <= end; d.setDate(d.getDate() + 1)) {
    const wd = d.getDay();              // 0=일 6=토
    if (wd === 0 || wd === 6) continue;
    if (HOLIDAYS_2026.has(ymd(d))) continue;
    out.push(ymd(d));
  }
  return out;
}

// 블록 시작 슬롯 c(k). stall 집합은 경험적 상수(테이블 역산).
const STALLS = [2, 3, 6, 10, 18, 23, 31];
function cOf(k) {
  let n = 0;
  for (const s of STALLS) if (s <= k) n++;
  return k + 1 - n;
}

// 검침일(1~31), 기준년/월(예: 2026, 5)
function getWorkableDates(meterDay, year, month) {
  const k = meterDay;
  const biz = buildBusinessDays(year, month);
  const at = (i) => biz[i - 1];          // b{i}

  const c = cOf(k);
  const L = (k <= 16) ? 12 : 11;         // 전체 블록 길이
  const jlen = (k <= 18) ? 2 : 3;        // 합동 칸수

  const blockEnd = c + L - 1;
  const Bend = blockEnd - jlen;
  const B = [], J = [];
  for (let i = c; i <= Bend; i++) B.push(at(i));
  for (let i = Bend + 1; i <= blockEnd; i++) J.push(at(i));

  // 전월잔여 A (k>=15)
  let A = [];
  if (k >= 15) {
    let Aend = c - 10;
    if (k === 15) Aend = 1;              // 경험적 패치
    if (k === 17) Aend = 3;             // 경험적 패치
    const Astart = Math.max(1, Aend - 11);
    for (let i = Astart; i <= Aend; i++) A.push(at(i));
  }

  const workable = A.concat(B).filter(Boolean).sort();
  const joint = J.filter(Boolean).sort();
  return { workable, joint };
}
```

## (d) 검증 결과

2026년 5월 검침일 **1~31 전수**를 위 JS 함수로 생성해 정답 테이블과 대조:

```
전체 31개 검침일 완전 일치 (불일치 0)
```

- 작업가능(노란)·합동시공(살구) 모두 날짜·개수·월넘김(5월→6월)까지 완전 일치.
- 검증된 구조적 특이점:
  - **완전 동일 행 그룹**: 1·2·3 / 5·6 / 9·10 / 22·23 / 30·31.
  - 검침일 17·18은 **메인 블록(c)은 같지만** 전월잔여 A에서 하루(5/11) 차이 — 동일 아님
    (k=17 Aend 패치가 이 차이를 만든다).
  - 합동 칸수 2→3 전환: 검침일 19부터.
  - 전체 블록 12→11 축소: 검침일 17부터.
  - 전월잔여 A 등장: 검침일 15부터, 검침일 28부터 Astart가 b1을 벗어나 앞이 잘림.

### 검증 코드 (node, .cjs로 저장해 실행)
함수 `getWorkableDates`를 import하고 검침일 1~31을 정답 테이블과 JSON 비교.
재현: `workable.cjs`(함수) + `verify.cjs`(대조) → `node verify.cjs`.
