# PM 핸드오프 — 관리자 검증 페이지(admin-validate) 리디자인

작성: 디자인 / 대상: PM·클로드코드 / 상태: **적용 준비 완료**

---

## 1. 한 줄 요약

데이터 검증 관리자 페이지를 **clay 디자인 + 블루 메인 + 다크모드 안전 토큰**으로 정리하고, **테마 설정(라이트/다크/시스템)**·**통계 재설계**·**검증 상세 모달 정리**를 적용했습니다. 백엔드 없이도 바로 열어볼 수 있습니다.

---

## 2. 이번에 적용된 것 (실제 파일 `admin-validate.html`)

1. **다크모드 정상화 (가장 중요)** — 하드코딩 hex 68건을 다크 안전 토큰(`--a-*`)으로 교체. 그동안 다크에서 배지·경고 글자가 사라지던 문제(당일작업·확인필요·확인완료·사진누락·정합성·스왑 등) 해결.
2. **테마 설정 이동** — 헤더 색스위처 제거 → **로그아웃 옆 `⚙ 설정`** 팝오버에 라이트/다크/**시스템(OS 자동추종)**. localStorage 유지.
3. **헤더 정리** — `flex-wrap`으로 좁은 폭에서도 제목이 안 깨지고 두 줄로 흐름.
4. **데모 모드** — `js/demo-shim.js`(자동 로그인 + 목업 fetch)로 백엔드(127.0.0.1:8765) 없이 전 화면·전 모달 미리보기 가능.

> ⚠️ **운영 배포 시**: `admin-validate.html`에서 `<script src="js/demo-shim.js"></script>` **한 줄만 삭제**하면 원래 백엔드를 씁니다. 로직·구조·함수명 변경 없음.

---

## 3. 별도 제안 (데모로 확인 → 적용 대기)

`관리자 검증 - 리디자인 제안.html` (리빙 샘플)에서 확인 가능:

- **통계 탭 재설계** — 가는 막대 → **도넛(완료율) + 권역 가로막대(진행률 색) + 축·그리드·값 있는 추이 차트(누적선 토글) + clay 질감**. 데이터 스키마는 실제 `/stats`·`/daily_stats`와 **동일**이라 그대로 호환.
- **통합 날짜 컨트롤** — 검증/통계/이력이 한 날짜 공유, **작업 있는 날 칩**으로 바로 점프(달력 헤매기 제거), 프리셋(오늘/어제/최근작업일).

> 적용하려면 실제 파일의 `renderStats`/`renderTrend` **출력부 교체** + 통합 날짜 컨트롤 마크업 추가가 필요합니다. 드롭인 스니펫 요청 주시면 제작.

---

## 4. 디자인 규칙 (신규 기능 추가 시 필수)

`관리자검증_디자인지침.md` 참고. 핵심:

- **clay 토큰만.** `--line`·`--accent` 같은 비-clay 변수 금지.
- **새 색은 hex로 박지 말 것** → clay 토큰 또는 `--a-*` 의미색. 진한 hex 텍스트는 다크에서 사라짐.
- **§3-1 hex→토큰 매핑표** — 앞으로도 hex가 들어오면 이 표대로 교체.
- 추가/변경 후 **반드시 다크로 토글해 글자 보이는지 확인.**
