## 3. P2 — 숫자가 조용히 달라진다

7/30 실사례: 전송탭에서 **84건 전체선택 → 확인모달 79건**. 5건이 어디서 왜 빠졌는지 화면이 말하지 않았다. 데이터탭 미완료 1건 vs 전송탭 제외 6건 불일치도 같은 성질.

완료(28)는 되돌릴 수 없다. **조용히 줄어드는 것보다 조용히 늘어나는 것이 더 위험**하다 — 7/29 커밋에 "한 건만 고른 줄 알았는데 89건이 통째로 나갔다"는 사고가 기록돼 있다.

**수정 방향**: 건수가 달라지는 모든 지점에 차이와 사유를 노출.

```
오늘 85건
  전송 가능  79
  제외        6   확인필요 5 · 사진 대기 1     [제외분 보기]
```

전송 확인 모달도 "85건" 한 줄이 아니라 **"85건 = 자동통과 71 + 확인완료 14"** 로 구성을 보일 것.

## 4. P3 — 모니터가 끊긴다 (백엔드 문제, 화면만 고치면 안 됨)

전송 1건의 실제 단계는 8개다. `awms_mtr_direct.py:951~1097`:

```
1 고객정보 조회(selectCustomerInfo)   2 작업목록 조회(mobMtr1000/getMainList)
3 사진 다운로드                        4 철거 저장(mobMtr5000/saveRow)
5 상세 조회(getDetail)                 6 자재 조회
7 신설 저장(mobMtr4000, 25)            8 완료(28) + 신설사진 재전송
```

**그런데 화면으로 나가는 로그의 phase는 "상세"·"완료" 둘뿐이다.** 7/30 job `c9a7f823` 로그 105건 = 계기당 2줄 + 시스템 3줄. 5·6·7단계가 "상세" 한 줄 msg 문자열에 뭉쳐 있다.

```
phase=상세  msg=getDetail 키수=303 / 확정차수=... | 자재: MTRL_NO=127825 | 신설4000 POST: 신설=... 봉인=...
phase=완료  msg=전송완료 seal=0315839 addr=창신동 138-18
```

건당 약 20초인데 그동안 화면이 안 움직이다가 두 줄이 동시에 떨어진다. 화면의 스텝 칸(`txStepGrid`, admin-validate.html:2019)은 4칸인데 백엔드가 2개만 주니 순서대로 켜질 수 없다.

**수정 방향**: 백엔드가 단계마다 로그를 흘려보낼 것(8 phase). 그러면 2~3초마다 화면이 움직인다. 로그 문구도 개발자용(`getDetail 키수=303`)이 아니라 사람용("상세 조회 완료")으로, 원문은 접어두기.

## 5. P4 — 매일 쓰는 것이 안 쓰는 것에 밀린다

전송탭 안에 섞여 있는 것: 등록 공사명(차수) · 봉인박스 범위 · 봉인 공사명 · 계정 목록 · 자동검증 토글 · 데이터셋 선택. **거의 다 매일 안 바꾸는 값**이고, 봉인박스는 **잘못 만지면 사고**라 오히려 자주 보이면 안 된다.

매일 쓰는 것은 셋뿐: 대상 고르기 · 전송 시작 · 진행 보기.

**수정 방향**: 설정 탭 분리.

```
설정 탭
  전송     등록 공사명(차수) · 계정 · 완료(28) 기본값
  봉인     봉인박스 범위 · 마지막 봉인 · 다음 번호 · 잔여
  자동화   자동검증 시각 · 켜짐 여부
  데이터   데이터셋 · 경로
```

마지막 봉인·다음 번호는 설정에 두고 전송 화면에는 **읽기 전용 한 줄**만. 7/30 "마지막 봉인 어디 갔냐" 질문도 값은 있는데 볼 자리가 없어서 나왔다(값은 `transmit_config.json` `seal_last`에 정상 보존 중).

- 첫 화면이 표라서, "지금 뭘 해야 하는지"를 사람이 판단해야 함

**수정 방향**: `오늘 / 데이터 / 전송 / 설정`

- **[오늘]** 신설 = 기본 화면. 마감 진행 + 처리 필요 큐. 열면 바로 "처리 필요 3건 / 전송 대기 85건"과 버튼
- **[이력]** 은 탭에서 빼고 데이터 상세 안으로
- **[설정]** 신설(P4)

초안:

```
2026-07-30 마감

 수집 85    검진 완료    처리 필요 6    전송 79/85    대조 대기
                         [처리하기]      [전송 시작]

 처리 필요 6건
   창신동 131-69   02171625092   검침값 확인필요   18798 / 16198   [사진] [확정]
   명륜3가 60-12   56170823035   계기번호 확인필요                 [사진] [재판독] [확정]
```

핵심 = **"처리 필요"가 최상단 단일 숫자**. 0이면 전송 가능, 아니면 왜 아닌지 바로 아래. 데이터탭·전송탭 왕복이 사라진다.
