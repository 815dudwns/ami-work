## 4. 계기 타입별 봉인 패턴 (14차 준공내역서 기준)

계기 타입은 신설계기번호(col8) 3~4번째 자리로 판별한다.

| 계기 타입 | 판별코드 | 공급방식 | 건수(14차) | 봉인번호1 | 봉인번호2 | 특이사항 |
|---|---|---|---|---|---|---|
| Amigo 단상 | 53 | 단상2선(220V) | 473 | 8자리 (배치공통) | 6~7자리 (계기별) | 전건 봉인2 있음 |
| Amigo 삼상 | 55 | 삼상4선(220/380V) | 58 | 8자리 (배치공통) | 6~7자리 (계기별) | 전건 봉인2 있음 |

14차는 계기번호 앞자리 분포: 53형(Amigo 단상) 473건, 55형(Amigo 삼상) 58건. E/EA/G 타입은 해당 차수에 없음.

6차 계기 타입 분포 (참고):
- 19형(EA) 409건, 53형(Amigo 단상) 359건, 45형(G 삼상) 8건

### 단상 vs 삼상 봉인 수량 차이 (14차 기준)

- **단상(1P2W)**: 봉인1(배치공통) 1개 + 봉인2(개별) 1개 = 총 2개 표기
- **삼상(3P4W)**: 봉인1(배치공통) 1개 + 봉인2(개별) 1개 = 총 2개 표기

14차 기준으로는 단상/삼상 모두 동일하게 봉인2가 전건 채워진다.
5~12차는 삼상에만 봉인2가 간헐적으로 채워지고 단상은 거의 없다.

## 6. awms 봉인 필드 대응

awms API 레퍼런스(`research/awms-poc/awms_API_레퍼런스.md`) 섹션 4 기준:

| awms 필드 | 설명 | 엑셀 대응 컬럼 | 비고 |
|---|---|---|---|
| `CSL_METR_TRML_SEAL_KND_CD` | 봉인종류 코드 | 엑셀 직접 대응 없음 | 고정값 `'A'` (스틱II 녹색) |
| `CSL_METR_TRML_SEAL_NO` | 봉인번호 | 5~12차: col13 / 13~14차: col14(개별번호) | awms에는 계기별 개별번호를 넣어야 함 |
| `METR_SEAL_VAL` | 봉인값 (다음 계기용 +1 시퀀스) | 엑셀에 없음 | mobMtr8000/getMainList 로 조회 후 +1 |
| 봉인번호2 | 미사용 | col14 | **영준님 지시: 봉인번호2 미사용, 봉인수량 1 고정** |
| 봉인수량 | 고정 1 | 무관 | 삼상도 1 (영준님 지시) |

### 핵심 대응 로직

```
5~12차 엑셀:
  실제 봉인번호 = col13 (봉인번호1)
  봉인자사번 = col12 (숫자 사번)

13~14차 엑셀:
  봉인 자재 종류 = col12 (예: 스틱II(녹색)-109541)
  배치 공통번호 = col13 (예: 18108755) — awms "봉인번호1" 에 해당할 수 있음
  계기별 개별번호 = col14 (예: 3966584) — awms CSL_METR_TRML_SEAL_NO 에 넣을 번호
```

awms saveAct/saveRow 자동등록 시: `CSL_METR_TRML_SEAL_KND_CD = 'A'`, `CSL_METR_TRML_SEAL_NO` = 해당 계기의 col14(개별봉인번호).
봉인자사번(col12)·봉인번호1(col13=배치공통)은 awms에 별도 필드로 넣지 않음(현재 레퍼런스에 매핑 없음).

### C. awms 필드 대응

- `CSL_METR_TRML_SEAL_KND_CD` = `'A'` (고정, 스틱II 녹색)
- `CSL_METR_TRML_SEAL_NO` = 엑셀 개별봉인번호 (5~12차: col13 / 13~14차: col14)
- `METR_SEAL_VAL` = awms 봉인조회(mobMtr8000/getMainList) 현재값 + 1 (엑셀과 무관, 시퀀스 카운터)
- 봉인번호2·봉인수량 복수 = 미사용 (삼상도 1개 고정)
