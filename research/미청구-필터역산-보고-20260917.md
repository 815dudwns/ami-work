## 4. 원장 → 작업중 진입 조건 — **확정, 반례 0, 완전 재현**

```
현장구분코드 == '0'  AND  구분 in {신규, 신설}   →  정확히 258,394건
```
규칙 O 인데 미진입 **0건** · 규칙 X 인데 진입 **0건**. (`Sheet1` 과 `작업중` 은 행집합·행순서 동일)

빠진 29,466건의 내역:

| 사유 | 건수 |
|---|---:|
| 현장구분코드 9 (철거) | 14,086 |
| 현장구분코드 3 (불가) | 11,271 |
| 코드 0 인데 구분이 기설 | 2,550 |
| 코드 0 인데 구분이 재방문 | 1,512 |
| 코드 0 인데 교체 45 · 재작성 1 · 철거 1 | 47 |
| **계** | **29,466** |

**뜻**: `작업중` 은 25년 보강공사의 **신규·신설 시공행만** 남긴 청구 대장이다.
철거·불가·기설·재방문·교체는 애초에 청구 단위가 아니라 들어가지 않는다.
상태(청구/미청구/불가)로 거른 것이 **아니다** — 빠진 29,466 안에 미청구가 3,912건 들어 있다.

**여기가 Sheet2 의 의미와 직결된다.** Sheet2 = 미청구인데 **그 계기에 신규·신설 시공행 자체가
원장에 없는 것**이다. 즉 "청구 근거가 될 시공행이 없어 청구 대장에 올릴 수조차 없는 계기" 다.
