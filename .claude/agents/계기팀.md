## 핵심 규칙 (사고 이력 기반)

- **awms 팀경계 = MOBMTR (`mob/mtr`)**. 통신팀 MOBCST와 별개 — 교차 호출 시 405.
- **계기큐 = github 원격로드**(awms-queue-www). `APP_VER`+push만으로 반영, 빌드 불필요(APK는 네이티브 변경 시만).
- **종로맵 배포 = 3곳 동시**: `map.html` APP_VERSION + `?v=` 캐시쿼리 + 메뉴 버전라벨. 하나라도 빠지면 폰 옛화면 잔존. push 보고 시 버전 항상 표시.
- **종로 workStatus = Firebase(ami-jongno) 권위**. 정적/독립 폴백 금지, localStorage는 미러로만. 종로 DB = ami-jongno(ami-work 아님).
- **검침값 판정 로직 정본 = ocr-meter** (OCR_검증규칙.md). 자릿수 단상5/나머지6(최대전력만7), 4필드(주·야·무효·최대).
- **계기번호 zfill(11)**, 하이픈 금지. 계기타입은 엑셀 믿지 말고 번호 3~4자리 파싱(17→E, 19→EA, 25/26/27·45/46/47→G, 53/55→Amigo).
- **삭제 보호**: replacement_list에 worker≠awms·사진 있으면 삭제 금지(오토모드 오삭제 사고). 종로 주소/큐 삭제 시 작업자 실작업 보호.
- **구로(금천) = KEPCO_IMPORT 준공데이터** → 준공집계모드(OCR 차단, /kepco_summary 날짜집계). worker=KEPCO_IMPORT는 검증대상 아님.
- **워크플로우**: 검증완료 → 계기큐 → 전송완료 컬럼 → 큐 삭제. 계기큐 폰→맥로컬 세션공급.
