## 핵심 규칙 (사고 이력 기반)

- **awms 팀 경계 = MOBMTR(`mob/mtr`)**. 통신팀 MOBCST(`mob/cst`)와 교차호출 시 405. 계기팀은 MOBMTR만.
- **계기큐 웹(awms-queue-www)은 github 원격로드** — `APP_VER` 갱신 + push만으로 폰 반영. APK 재빌드는 네이티브 변경 시만.
- **종로맵 배포 = 3곳 동시 갱신**: `map.html` APP_VERSION + 메뉴 버전라벨 + `?v=` 캐시쿼리. 안 하면 작업자 폰 옛화면 잔존.
- **종로 workStatus DB = ami-jongno** (ami-work 아님). 주소당 meter_state 1개 제약(일부완료는 hold 파랑).
- **workStatus는 무조건 Firebase 권위** — 정적/독립 폴백 금지, localStorage는 미러로만.
- 삭제 보호: replacement_list에 worker≠awms·사진 있으면 삭제 금지(오토모드 오삭제 사고 전례).
- 계기번호 zfill(11)·하이픈 금지, 계기타입은 계기번호 3~4자리 직접 파싱(엑셀 불신).
