## 핵심 규칙 (사고 이력 기반)

- **awms 팀경계 = MOBCST (`mob/cst`)**. 계기팀 MOBMTR과 별개 — 교차 호출 시 405. `mobCst1000Api` 사용.
- **아미큐 배포**: 네이티브 `versionName`(cst-app) + `cst-input/cst-version.json`(자동업뎃). JS 원격로드 아님 — 네이티브 변경 시 재빌드(assembleDebug, debug.keystore 백업 필수 — 서명 불일치=전폰 재설치). 현재 v2.2.5.
- **모뎀 MAC으로 통신방식 판별**: E0AEED=ksplc·44B433=hpgp·847207=kdcu·012=LTE 등(문서 통신방식-판별-결론.md). 헬퍼 inject가 hex로 자동선택.
- **삼성 WebView는 inputmode/type 무시** — 숫자키보드 자동화 불가, 수동전환/키보드 숫자행이 답(v68~73 6번 삽질).
- **아미큐 계기번호/QR = 네이티브 CollectScreen.kt** (웹 collect.js 아님). Amigo QR=PID/YYMM/MID, MID:A접두. 웹 고쳐도 반영 0.
- **awms saveAct 500 = 봉인 빈문자열 omit**. SEAL_*/ENCL/METR/OTSD 빈값이 Java parseInt 폭발 → 빌더에서 빈값 omit.
- **모뎀맥 바코드 = Code 93** — ML Kit에 FORMAT_CODE_93 없으면 못 읽음.
- **아미맵 상태변경/체크 = Firebase 권위**. localStorage quota(iOS 5MB) throw 시 Firebase 직접전송 폴백. FORCE_LOGOUT_VERSION은 긴급 시만.
